# 23 Games Museum: the public site (read-only print)

Static JSON and images, generated by the curator app's Publish action (`02_APP_AND_AGENTS/_build/publish_public.py`).
Nothing in this repo can write state. No onboarding, no device picker, no import, no backup routes.

- `public/data/items.json`, `collections.json`, `quests.json`, `stories.json`: public fields only (a whitelist).
- `public/img/<5-digit id>.jpg` and `_t.jpg`: the item's own photo, by item id.
- Item address, decided once and never changed: `https://23gamesdigital.com/i/<5-digit id>` (printed QR codes carry it forever).
- Netlify: publish directory `public`, `_redirects` sends everything to `index.html` for now.

Never deploy the curator app from here. Never add a write path to this bundle.
